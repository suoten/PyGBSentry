# 可视化管理截图资产目录说明

## 1. 目录用途
- 存放可视化管理文档截图。
- 供“可视化管理”相关文档统一引用。
  - 当前仓库暂未落地独立的 `VISUAL_ADMIN_GUIDE.md`；若后续新增该文档，可优先复用本目录下的截图资产。

## 2. 命名规则
- 文件名：`<模块>-<页面>-<动作>-v1.png`
- 示例：`plugin-center-add-platform-form-v1.png`

## 3. 必备截图清单（当前状态）

> - 若某条目对应的功能/页面已删除或不再在文档中出现，应删除该条目或在条目后标注“已废弃（不再需要）”，避免长期悬空。

## 4. 截图质量要求
- 分辨率不低于 1920x1080。
- 保持原比例，不裁切关键信息。
- 涉及账号、密码、Token、IP、设备编号时必须脱敏。

## 5. 交付与回填规则

- 截图应与文档描述一致：若 UI 已调整但截图未更新，视为“文档未回填”。
- 每次补齐截图后，建议在对应文档段落旁补一句“截图更新时间/版本”（例如 `v1` -> `v2`），避免长期引用过期 UI。
