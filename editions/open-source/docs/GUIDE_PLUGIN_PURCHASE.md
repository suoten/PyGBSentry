# 插件中心使用指南

> 本文档面向终端用户（非开发者），说明如何在 PyGBSentry 官方版插件中心浏览、购买和管理插件。
> 更新时间：2026-04-13

---

## 什么是插件

插件是 PyGBSentry 官方版的功能扩展模块。通过安装插件，你可以为平台增加额外的功能，例如：

- **车牌识别** — 自动识别进出车辆的车牌号码
- **人脸考勤** — 基于人脸识别的考勤统计
- **区域入侵检测** — 智能识别异常闯入行为
- **烟火探测** — 烟雾/火焰自动检测报警
- ……以及更多插件

---

## 进入插件中心

1. 登录 PyGBSentry 官方版平台
2. 在左侧菜单中找到「插件中心」或「应用市场」入口
3. 点击进入插件中心首页

---

## 浏览插件

在插件中心首页，你可以看到所有可用的插件列表。

**筛选方式：**

| 筛选条件 | 说明 |
|----------|------|
| 全部插件 | 显示所有插件 |
| 官方认证 | 由 PyGBSentry 官方团队开发和维护 |
| 免费插件 | 无需付费即可安装使用 |
| 付费插件 | 需要购买后才能安装 |

**查看插件详情：**

点击任意插件卡片，进入插件详情页，可以看到：
- 插件名称与版本
- 插件功能介绍
- 支持的设备类型
- 定价与计费方式
- 用户评价与评分

## 购买插件

### 步骤 1：选择计费方式

插件通常支持以下计费方式：

| 计费方式 | 说明 |
|----------|------|
| **一次性买断** | 付一次费用，永久使用 |
| **按年订阅** | 按年付费，续费后可继续使用 |
| **按月订阅** | 按月付费，适合短期使用 |
| **免费** | 无需付费，直接安装 |

### 步骤 2：完成支付

1. 点击插件详情页中的「立即购买」或「订阅」按钮
2. 确认订单信息（插件名称、价格、计费周期）
3. 选择支付方式（微信支付 / 支付宝）
4. 完成支付

> **支持微信支付和支付宝**：支付过程中，您可以选择微信扫码支付或支付宝扫码支付。

### 步骤 3：安装插件

支付成功后，返回插件中心页面，点击「安装」按钮将插件安装到你的平台。

安装完成后，插件会自动出现在平台的插件管理列表中。

## 管理已购插件

### 查看已购插件

登录平台后，进入「我的插件」或「已购插件」页面，可以查看所有已购买并���装的插件。

### 更新插件

如果插件有新版本可用，「我的插件」页面会显示更新提示。点击「更新」按钮即可升级到最新版本。

### 续费

对于订阅制插件（如按年/按月订阅），在插件到期前，「我的插件」页面会显示续费提示。请在到期前完成续费，避免插件功能中断。

### 卸载插件

如需卸载某个插件，进入「我的插件」页面，点击该插件的「卸载」按钮。卸载后插件功能将立即停止。

> 注意：卸载插件不会退款。如需退款，请参考退款政策联系客服。

## 常见问题

### Q：购买后可以退款吗？

A：一般情况下，付费插件购买后不支持退款。如有特殊情况，请联系客服处理。

### Q：可以用公司账户购买吗？

A：可以。支付时请选择「对公转账」或联系商务同事开具采购订单。

### Q：一个账号可以安装多个插件吗？

A：可以。同一个平台账号可以购买和安装多个不同功能的插件。

### Q：插件数据会丢失吗？

A：卸载插件时，插件产生的数据（如识别记录、统计报表等）是否保留，取决于插件本身的设计。部分插件支持数据导出，请在卸载前确认。

### Q：遇到问题找谁？

A：如遇到购买、安装、使用方面的问题，请通过平台内的「联系客服」入口提交工单，客服团队会尽快回复。
