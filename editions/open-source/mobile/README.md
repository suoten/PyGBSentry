# PyGBSentry 开源版手机端（uni-app）

## 说明

- 本目录为开源版手机端工程，采用 `uni-app + Vue3 + TypeScript + Pinia`。
- 目标：承载“首页/设备/预览/告警/我的”五大核心域，并支持移动插件动态入口。

## 快速开始

```bash
cd editions/open-source/mobile
npm install
npm run dev:h5
```

## 环境变量

- `VITE_API_BASE`：后端 API 地址前缀；为空时走相对路径（可配合 dev proxy）。
- `VITE_DEV_API_TARGET`：本地开发代理目标地址，默认 `http://localhost:8000`。

## 已接入能力

- 登录与用户信息：`/api/v1/login/access-token`、`/api/v1/users/me`
- 设备与告警：`/api/v1/devices/*`、`/api/v1/alarms/*`
- 实时预览：`/api/v1/stream/play/{device_id}/{channel_id}`
- 移动插件入口：`/api/v1/plugins/mobile-entries`
- 预览增强：自动轮询流状态、线路优选、手动回退、单屏/四分屏框架
- 告警处置：确认（ack）、升级（escalate）、派单（work-order create）
- 工单流转：接单（in_progress）、解决（resolved）、关闭（closed）
- 播放观测：流健康评分展示（可用时自动获取）
- 移动指挥：地图态势、轨迹加载、会商创建/加入、指令发布与结束会商
- 指挥联动：点位选中自动拉流预览、会商成员列表、指令 5 秒自动刷新
- 会商提效：支持“当前设备会商”一键创建，并自动写入设备上下文指令
- 预览观测：健康评分支持 10 秒自动刷新轮询
- 告警联动：告警列表支持“一键会商联动”，自动带入告警与设备上下文
- SLA 看板：告警中心已接入 `/api/v1/alarms/sla/overview`（待处理、超时、升级、确认效率）
