## 什么是 PyGBSentry

**PyGBSentry** 是一个基于最新 **GB/T 28181-2022** 国家标准构建的现代化网络视频平台（向下兼容 GB/T 28181-2016 设备），负责核心信令交互与设备管理后台。

**它能做什么？**

本系统用于将散落在各处的摄像头、NVR、传统监控系统统一汇聚，实现一站式看、存、管、控、用：

- 兼容 **海康威视、大华、宇视** 等主流品牌设备即插即用
- 支持 **国标级联**（上下级平台对接）、**多协议视频流转发**（RTSP/RTMP 转国标）
- 支持 **直播推流接入**（RTMP 推流转国标）及 **GIS 可视化指挥**
- 支持 **NAT 穿透**，适配复杂网络环境

**技术栈**：Python (FastAPI) + Vue 3 + ZLMediaKit，Docker 一键部署，开源可商用（MIT 协议）。

## 核心功能一览

### 1. 国标接入与信令

- 基于 GB/T 28181-2022 标准实现（向下兼容 2016/2011 设备）
- UDP/TCP 双模式、NAT 穿透、网络校时
- 设备状态实时监控（信号/存储）、主副码流切换

### 2. 极致的视频与录像体验

- 1/4/9/16/25/36 多分屏实时预览，浏览器无插件播放（H.264/H.265）
- PTZ 云台控制、预置位轮巡、电子放大
- 双向语音广播与对讲
- 云端录像集中存储，时间轴精准检索、多路同步回放、快进快退

### 3. GIS 地图与可视化指挥

- 设备精确落图，鹰眼、测距、自定义矢量瓦片与图层控制
- 报警点位地图实时闪烁、点击视频自动联动、报警轨迹追踪

### 4. 立体报警与事件联动

- 移动侦测、越界入侵、视频丢失等设备报警接入与 Web 实时推送
- 报警自动触发云端录像、抓图、通知推送及电视墙联动上墙

### 5. 平台级联与精细权限

- 向上级联注册保活、目录自动推送、视频录像共享、GPS 订阅
- 多租户、RBAC 角色权限控制、行政区域树管理
- API 接口鉴权、操作审计日志

### 6. 插件扩展生态

- 内置插件管理器，支持移动端（App/小程序）、AI 智能分析等扩展插件无缝接入

## 常见问题

### 小白也能部署吗？

**完全可以。** Docker 一键部署只需 3 条命令即可拉起全套服务，文档详尽记录了 90% 以上的常见报错及解决方案。

### 开源版可以商用吗？

**可以。** MIT 许可证，保留版权信息即可用于商业项目。核心监控链路（设备接入、预览回放、GIS、报警联动、级联等）完全免费。

### 文档和代码同步吗？

**是的。** 文档按当前代码仓库最新结构组织，每篇优先给出"可执行的操作路径 + 可验证的接口 + 明确的失败排查建议"。
