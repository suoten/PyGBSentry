# 国标设备接入配置指南

> 本文档详细说明在摄像头/NVR 设备侧如何配置 GB/T 28181 参数以接入 PyGBSentry 平台。
> 适用于：海康威视、大华、宇视、水星等主流品牌设备。
> 更新时间：2026-04-13

---

## 1. 前置知识：需要配置的参数

设备接入前，需在设备侧配置以下 SIP 参数。这些参数必须与 PyGBSentry 平台侧配置**完全一致**：

| 参数名 | 说明 | 获取方式 |
|--------|------|----------|
| **SIP 服务器地址** | PyGBSentry 服务器 IP 或域名 | 平台管理界面 → 系统设置 |
| **SIP 服务器端口** | 固定为 `5060`（UDP/TCP） | 平台管理界面 → 系统设置 |
| **SIP ID（设备横号）** | 20 位国标编码，平台唯一标识 | 平台管理界面 → 系统设置 |
| **SIP 域（Domain）** | 通常取 SIP ID 的前 10 位 | 平台管理界面 → 系统设置 |
| **认证密码** | 设备注册时校验的密码 | 平台管理界面 → 系统设置 |
| **心跳周期** | 建议 `60` 秒 | 设备侧可选配置 |

## 2. 海康威视设备配置

### 2.1 IPC（网络摄像机）配置步骤

1. **进入配置页面**
   使用浏览器访问摄像头 IP，登录后进入「配置」选项卡。

2. **打开国标协议开关**
   「网络」→「高级设置」→「平台接入」→ 勾选「启用 GB/T 28181」

3. **填写参数**

   | 配置项 | 示例值 | 说明 |
   |--------|--------|------|
   | 服务器地址 | `192.168.1.100` | PyGBSentry 服务器 IP |
   | 服务器端口 | `5060` | SIP 监听端口 |
   | SIP 横号 | `34020000001110000001` | 平台分配的 20 位 ID |
   | SIP 域 | `3402000000` | 取横号前 10 位 |
   | 通道横号 | `34020000001310000001` | 设备自身 20 位编码 |
   | 用户名 | `34020000001310000001` | 通常同通道横号 |
   | 密码 | `12345678` | 与平台认证密码一致 |
   | 心跳周期 | `60` | 秒 |

4. **保存并等待注册**
   保存后，设备会自动尝试向平台注册。回到 PyGBSentry 管理界面，刷新设备列表，确认设备状态为「在线」。

### 2.2 NVR（网络录像机）配置步骤

NVR 的配置与 IPC 基本一致，区别在于：
- SIP 横号填写 NVR 设备本身的 20 位编码
- 通道横号填写 NVR 下挂摄像头的 20 位编码
- 如果 NVR 接入多台摄像头，通常只需配置 NVR 本身的国标，摄像头通道由 NVR 自动推送

> **配置入口**：`配置` → `网络` → `平台接入`（或 `国标平台`）

### 2.3 海康设备常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 注册失败 401 | 密码错误 | 核对平台侧认证密码 |
| 注册失败 403 | IP 未授权 | 检查平台是否限制了设备 IP |
| 设备在线但无通道 | NVR 未开启自动推送 | 在 NVR 侧开启「通道自动上报」 |
| 视频无法播放 | 设备码流为 H.265+Audio | Web 播放器需 AAC 音频，建议设备改为 H.264 或静音 |

## 3. 大华设备配置

### 3.1 IPC 配置步骤

1. **登录设备 Web 界面**
   访问设备 IP，进入「设置」→「网络」→「平台接入」。

2. **启用国标协议**
   选择协议类型为「GB/T 28181」或「28181」，启用接入功能。

3. **填写参数**

   | 配置项 | 示例值 |
   |--------|--------|
   | 协议类型 | GB/T 28181 |
   | 服务器地址 | `192.168.1.100` |
   | 服务器端口 | `5060` |
   | SIP 橇号 | `34020000002110000001` |
   | 橇号 | `3402000000` |
   | 设备橇号 | `34020000002310000001` |
   | 密码 | `12345678` |
   | 心跳间隔 | `60` |

4. **保存**
   保存后观察设备状态，确认注册成功。

### 3.2 大华 NVR 配置步骤

大华 NVR 配置国标入口：`设置` → `网络` → `平台注册`

- NVR 本身注册后，通道（摄像头）会自动同步到平台
- 如果通道未自动出现，可能需要手动「刷新通道」

### 3.3 大华设备注意事项

- 大华设备默认**不勾选**「收到 ACK 后发流」选项（语音对讲场景除外）
- 部分大华老设备仅支持 GB2312 编码，若平台显示通道名乱码，需在平台侧将字符集切换为 GB2312

## 4. 宇视科技设备配置

### 4.1 IPC 配置步骤

1. **登录设备**
   访问宇视摄像头 IP，进入「系统」→「网络」→「平台对接」。

2. **新建国标接入**
   选择「28181」协议，填写以下信息：

   | 配置项 | 示例值 |
   |--------|--------|
   | 服务器地址 | `192.168.1.100` |
   | 服务器端口 | `5060` |
   | 本域橇号 | `3402000000` |
   | 设备橇号 | `34020000003310000001` |
   | 设备密码 | `12345678` |
   | 传输模式 | UDP / TCP 自适应 |

3. **保存并验证**
   确认设备在平台侧显示在线。

### 4.2 宇视 NVR 配置步骤

宇视 NVR 的国标配置入口通常在：「配置」→「网络服务」→「28181 平台」

- NVR 注册成功后，下挂通道自动上报
- 宇视 NVR 支持通道选择推送，可按需配置只推送部分通道

---

## 5. 水星（MERCURY）设备配置

水星/水星商用系列摄像头的国标配置相对简单：

1. **登录设备**
   访问设备 IP，进入「设置」→「网络」→「平台接入」。

2. **配置参数**

   | 配置项 | 示例值 |
   |--------|--------|
   | 启用 | 勾选 |
   | 服务器地址 | `192.168.1.100` |
   | 端口 | `5060` |
   | 橇号 | `3402000000` |
   | 设备 ID | `34020000004310000001` |
   | 密码 | `12345678` |

3. **保存**
   确认注册状态。

> 注意：部分水星设备固件版本较旧，可能不支持国标协议或仅支持 UDP 模式，建议升级固件到最新版本。

## 6. 通用排查流程

当设备无法注册时，请按以下顺序排查：

### 步骤 1：网络连通性

```bash
# 在设备同一网段或可互通的网络中测试
telnet 192.168.1.100 5060
# 或
nc -vzu 192.168.1.100 5060
```

若端口不通，检查：
- 服务器防火墙是否放行了 5060/UDP 和 5060/TCP
- 服务器安全组（云服务器）是否放行对应端口
- 设备与服务器是否在同一可路由网段

### 步骤 2：SIP 参数核对

确认设备侧与平台侧以下参数**完全一致**：
- SIP 服务器地址（IP 或域名）
- SIP 端口（必须为 5060）
- SIP 橇号（20 位）
- 认证密码

### 步骤 3：查看平台日志

在 PyGBSentry 管理界面或服务器日志中，搜索设备横号，查看注册被拒绝的具体原因：

```
# 常见拒绝原因
401 Unauthorized   → 密码错误
403 Forbidden       → IP 未授权 / 设备被禁用
404 Not Found       → 设备横号在平台不存在
```

### 步骤 4：抓包分析

使用 tcpdump 在服务器抓包，确认 SIP REGISTER 请求是否到达：

```bash
# 抓取 5060 端口 SIP 信令
tcpdump -i any -n port 5060 -c 100 -w /tmp/sip.pcap

# 或实时查看
tcpdump -i any -n port 5060 -v
```

将 `.pcap` 文件下载到本地，用 Wireshark 打开分析。

## 7. 配置参数参考表

| 参数 | 说明 | 典型值 |
|------|------|--------|
| SIP 服务器地址 | 平台 IP 或域名 | `192.168.1.100` 或 `video.example.com` |
| SIP 端口 | 固定 5060 | `5060` |
| SIP 橇号 | 平台 ID，前 10 位为域 | `34020000001110000001` |
| SIP 域 | 通常取橇号前 10 位 | `3402000000` |
| 认证密码 | 平台与设备约定的密钥 | `12345678` |
| 心跳周期 | 建议 30-60 秒 | `60` |
| 传输协议 | UDP / TCP | `UDP`（默认） |
| 注册有效期 | 注册有效期，需大于心跳 | `3600` |

---

## 8. 平台侧查看与操作

配置完成后，在 PyGBSentry 管理界面进行以下操作：

| 操作 | 位置 | 说明 |
|------|------|------|
| 查看设备列表 | 设备管理 → 国标设备 | 确认设备在线状态 |
| 刷新通道 | 设备行末「刷新」按钮 | 更新设备通道信息 |
| 编辑设备 | 设备行末「编辑」按钮 | 修改密码、收流 IP 等 |
| 删除设备 | 设备行末「删除」按钮 | 移除设备（设备下次注册会重新出现） |
| 批量导入 | 设备管理 → 批量导入 | 批量注册设备信息 |
