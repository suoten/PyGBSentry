# 开源一个纯 Python 的 GB28181 视频监控平台:我们把同类项目 456 个 issue 读完,才敢发布

(适合公众号 / V2EX / 少数派风格,配 2-3 张截图:监控中心、播放诊断报告、部署体检)

做视频监控平台的朋友,大概率经历过这些场景:

- 点播永远"收流超时",查了一晚上发现是 ZLM 的 secret 或者公网地址没配对;
- 设备明明在线,通道却显示离线;
- 录像计划设好了,服务器一重启就不录了;
- 大华摄像头喊话死活不通,海康却没问题;
- 想把画面嵌进自己的业务系统,iframe 一开就是跨域 404。

这些不是玄学,是 GB28181 平台的高频病。

**PyGBSentry** 是我们的答案:纯 Python 自研 SIP 协议栈(没有黑盒,每条信令可打断点)、FastAPI + Vue 3、集成 ZLMediaKit,基于 GB/T 28181-2022 向下兼容 2016。Windows 一键安装包、Docker Compose、便携版 zip,四条部署路线任选。

发布前,我们干了一件笨事:把同类最流行开源项目的 **456 个公开 issue** 全部读完,逐条对照自己的代码做了两轮审计。该绕的坑绕开,该修的修掉,还顺手做了一批同类项目用户苦苦等待的能力:

- **播放失败自诊断**:点播失败不再是黑盒,六道关卡直接告诉你哪一步错了、怎么修;
- **部署体检**:运维中心一键九项检查,SIP/数据库/流媒体节点/公网地址/安全基线;
- **对讲自动适配**:大华、海康混部不用手工选模式,平台自动探测;
- **一键分享/嵌入**:HMAC 签名嵌入页,第三方系统 iframe 直播视频;
- **MP4 虚拟通道**:上传本地视频文件,当直播源循环播;
- **流量账单**:按通道累计流量报表,谁在偷吃带宽一目了然;
- **API 契约**:端点快照进 CI,只增不减,集成者升级零惊喜。

纯 Python 意味着:秒级启动、源码可读、AI 生态开箱即用,想二次开发不用啃 Java 巨型工程。
