# PyGBSentry 开源版产品说明

> 本文档用于说明开源版的功能边界、适用场景与能力定位。

---

## 一句话介绍

PyGBSentry 开源版是一个面向 GB/T 28181 场景的监控平台，覆盖从设备接入、实时预览、录像回放到 GIS 可视化、运维审计的完整业务链路，并通过插件机制持续扩展能力。

---

## 核心价值

| 维度 | 说明 |
|------|------|
| **落地快** | Docker 一键部署，也支持手工部署 |
| **能力全** | 覆盖接入、播放、回放、报警、地图、级联、运维 |
| **可扩展** | 插件机制支持业务扩展，避免频繁修改核心代码 |
| **可治理** | 配置中心草稿发布、审计中心留痕、诊断接口可巡检 |

---

## 能力全景

### 1. 国标接入与信令

| 功能 | 说明 |
|------|------|
| GB/T 28181-2022 设备/平台接入（兼容 2016） | IPC、NVR、级联平台即插即用 |
| UDP/TCP 双模式 | 适配不同网络环境 |
| 网络校时 | 自动与手动两种模式 |
| 上下级平台级联 | 注册保活、目录推送、共享、状态同步、GPS 订阅 |

### 2. 视频业务

| 功能 | 说明 |
|------|------|
| 实时预览 | 多分屏（1/4/9/16/25/36），无插件浏览器播放 |
| 主副码流切换 | 按需切换，节省带宽 |
| 云台与预置位控制 | 支持 Pelco-D/P 协议云台 |
| 录像检索与回放 | 支持时间轴 seek、快进快退 |
| 语音广播与对讲 | G.711A/U 音频编码链路 |

### 3. 流媒体与存储

| 功能 | 说明 |
|------|------|
| 多协议分发 | 基于 ZLMediaKit，支持 RTSP/RTMP/FLV/HLS/WebRTC |
| RTP 端口段与多节点 | 支持范围模式和单端口多路复用 |
| 云端录像链路 | 录像回调与存储配置管理 |
| 录像计划 | 灵活的存储策略配置 |

### 4. 报警与联动

| 功能 | 说明 |
|------|------|
| 报警接收与实时推送 | WebSocket 实时送达 |
| 报警录像联动 | 触发录像、截图、通知 |
| 升级与确认机制 | SLA、确认、升级与审计闭环 |

### 5. GIS 与可视化

| 功能 | 说明 |
|------|------|
| 地图点位落图 | 支持多种地图源 |
| 鹰眼与测距 | 空间辅助分析 |
| 图层控制 | 矢量瓦片、自定义图层 |
| 可视化指挥 | 轨迹追踪、视频联动 |

### 6. 运维与治理

| 功能 | 说明 |
|------|------|
| 审计中心 | 关键操作留痕 |
| 配置中心 | 草稿发布与回滚 |
| 健康诊断接口 | `/api/v1/ops/db-check`、`/api/v1/ops/diagnose-report` |

### 7. 数据库与部署

| 形态 | 说明 |
|------|------|
| PostgreSQL / MySQL / SQLite | 按需选择 |
| 国产数据库兼容 | 金仓、达梦（需项目环境验证） |
| Docker 支持 | 一键部署，自含 ZLMediaKit |

---

## 功能边界

### 开源版包含

- 监控主业务能力（接入、预览、回放、报警、GIS、级联、运维）
- 插件运行与插件接口能力

### 开源版不包含

- 商业插件市场审核与上架流程
- 支付与订阅结算（这部分由服务器版承担）
- 许可证签发私钥体系

---

## 推荐场景

| 场景 | 说明 |
|------|------|
| 政企内网监控平台 | 安全隔离网内的标准国标接入 |
| 园区/行业私有化项目 | 私有化部署，无需公网依赖 |
| 智慧城市建设 | 海量点位接入，公安/交警/城管多级共享 |
| 老旧系统利旧改造 | 将 RTSP/ONVIF 设备低成本接入转为国标流 |
| 可视化应急指挥 | 结合 GIS 地图与报警联动实现高效调度 |

---

## 推荐部署形态

| 场景 | 推荐配置 |
|------|---------|
| 试用/演示 | SQLite + 同机 ZLM |
| 生产环境 | PostgreSQL + Redis + Nginx + ZLM（同机或独立） |
| 跨网/公网 | 按 `INSTALL_DEPLOY.md` 的 NAT 与端口章节逐项校验 |

---

## 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|---------|---------|
| Python | 3.10 | 3.10+ |
| Node.js | 16 | 18+ |
| PostgreSQL | 12 | 14+ |
| Redis | 6 | 6+ |
| ZLMediaKit | 内置 | Docker 镜像内置最新稳定版 |

### 硬件建议

| 配置 | 场景 |
|------|------|
| 2核CPU / 4GB RAM | 仅信令 + 少量流转发 |
| 4核CPU / 8GB RAM | 支持 AI 分析或多并发 |
| 8核CPU / 16GB RAM | 中大型项目生产环境 |
